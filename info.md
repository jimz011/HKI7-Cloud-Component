# HKI 7 Cloud

HKI 7 Cloud is the Home Assistant integration used by the HKI 7 Android app.
It provides authenticated, local-only WebSocket storage for app backups, family
dashboard sharing, parental-control preferences, and related app data.

## Installation

Install through HACS, restart Home Assistant, then add **HKI 7 Cloud** from
**Settings → Devices & Services**. The integration has no configuration options.

For complete installation instructions, requirements, and supported WebSocket
commands, see the [README](README.md).
